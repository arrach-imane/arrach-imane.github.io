Projets en cybersécurité

SOC et détection

CabinetShield – Détection et supervision de la sécurité réseau

Solution locale de supervision réseau pour petits cabinets médicaux, avec IDS Suricata pour détecter les activités suspectes. Collecteur Python (traitement, normalisation, déduplication des alertes) intégré à une API REST, une base SQLite et un tableau de bord de suivi. API sécurisée et données locales protégées.

Outils : Debian Linux, Suricata, Python, Flask, SQLite, API REST, HTML/CSS/JavaScript

Cloud computing et sécurité

Architecture Zero Trust en environnement virtualisé

Comparaison d'un réseau plat avec une architecture Zero Trust en 6 zones (OPNsense, moindre privilège), avec IAM Keycloak, MFA Authelia, reverse proxy Traefik (TLS) et supervision Wazuh. Une même chaîne d'attaque (Nmap, Hydra, exfiltration, interception HTTP) est rejouée avant et après segmentation pour quantifier la réduction de la surface d'attaque.

Outils : OPNsense, Keycloak, Authelia, Traefik, Wazuh, Nmap, Hydra, Wireshark, VirtualBox
